# Multiplatform Mobile Software Engineering in Practice

**AGH University of Krakow**

In this course you build mobile apps for Android and iOS with **Flutter**, and you practise the engineering habits that professional teams rely on: version control, code review, verification, and working responsibly with coding agents. The **Mood Tracker** app runs through the course as the shared example; later you build an app of your own in a team.

!!! tip "Course materials repository"
    Lab exercises, starter projects and templates live in the course repository:

    **<https://github.com/MDaniolAGH/multiplatform>**

    Clone it once, then run `git pull` before each lab:

    ```bash
    git clone https://github.com/MDaniolAGH/multiplatform.git course-materials
    ```

## How the Course Works

The course has **13 meetings**. Each meeting has a **90-minute lab** followed by a **90-minute lecture**. The lab comes first on purpose: you try things hands-on, and the lecture then explains and deepens what you met in the lab.

Materials are published here as the course progresses.

## Assessment

| Component | Weight |
|-----------|--------|
| Individual foundations: assignments A1, A2 and A3, from Labs 1–3 (5% each) | 15% |
| Sprint reviews (3×) | 25% |
| Final project and presentation | 50% |
| Peer evaluation | 10% |

Each assignment's task, deadline and grading criteria are in its lab workbook. Details and dates of the team components are published later in the course.

## Working with AI Tools

- **Labs 1–3 and assignments A1–A3 are independent work: no AI coding tools.** The aim is to build a genuine understanding of the foundations. You may be asked to explain your code, or to change it without help.
- **From Lab 4 onwards** you will also work with a coding agent. The course supports **GitHub Copilot**, which is free for students verified through [GitHub Education](https://education.github.com), and **Mistral Vibe**, which has a free plan with a limited number of coding sessions. Apply for GitHub Education early: verification can take several days.
- The full rules for agent-assisted work are published before Lab 4.

## Prerequisites

- Basic programming experience (Python, C/C++ or similar)
- A laptop that can run Flutter (macOS, Windows or Linux)
- No prior experience with Git, the terminal or mobile development is expected

Start with [Getting Ready](resources/GETTING_READY.md).
